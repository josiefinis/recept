# Bara Pannkakor 
This project was part of the frontend education with Lexicon and was developed during the first course, covering modern HMTL5 and CSS3. 

## :star: Features
- *Enkelt recept på pannkakor* recipe page created from Figma reference
- *Recept* page with grid layout of recipes
- Simple *log in* form
- Extensive *create account* form
- Responsive design
- Accessible design conforming to WCAG and tested with WAVE and Lighthouse

## :eye: Demo
[Visit page](https://josiefinis.github.io/recept/recept.html)

## :wheel: Under the hood
- Semantic HTML5
- Modern CSS following CUBE naming convention
- Flex and Grid layouts
- Media och container queries
- oklch color system

## :sewing_needle: Technologies
- HTML5
- CSS3
